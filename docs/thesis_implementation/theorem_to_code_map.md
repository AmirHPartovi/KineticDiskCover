# Thesis implementation traceability map

This map links the operational statements in Chapters 5 and 6 to the current
implementation and tests. Test results are regression evidence, not proofs.
In particular, successful `FAST_DOUBLE` tests do not establish validated
arithmetic, continuous certification, or convergence.
References use the thesis section/equation/table identifiers recorded in the
local source extraction. Where an exact subsection or theorem number was not
recoverable, the map cites the bounded source discussion rather than
attributing an unverified theorem number.

Assurance labels:

- `proved-by-design`: the code structure enforces the stated discrete
  invariant, subject to its inputs and arithmetic.
- `validated-arithmetic`: the relevant numerical operations use a validated
  enclosure backend. No current implementation is assigned this level.
- `numerical-only`: checked with ordinary floating-point calculations and
  synthetic/reference examples; not a mathematical certificate.
- `not-implemented`: absent, or unavailable at the assurance level required
  by the thesis.

## Known assurance gaps

- There is no validated interval-arithmetic backend. `VALIDATED` modes therefore
  refuse certification or report unavailable/not-certified; `nextafter`,
  `long double`, and tolerances do not change that assurance level.
- Upper-envelope roots are computed with floating-point formulas and close-root
  heuristics. The code can report indeterminate cases, but it does not provide
  certified root enclosures or a proof of root ordering.
- Snapshot V1 retains its original constant-radius meaning. Snapshot/program
  V2 stores piecewise quadratic `q_i(t)` and time origins; both are loaded by
  explicit schema tags. Its outward-rounded integral is a numerical diagnostic,
  not a validated enclosure of the original geometric computation.
- Tests establish implemented behavior on selected deterministic inputs.
  They do not prove a general convergence statement or validity for all
  instances.
- The local extraction did not support reliable theorem numbers for the
  interval-bound and envelope claims beyond the cited equations/sections;
  those rows deliberately avoid assigning unverified theorem labels.
